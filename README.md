# FUTURE_ML_02
🤖 Text Classification with Naive Bayes: This project trains a **Multinomial Naive Bayes** model to classify support queries into categories like Technical, Billing, Account, and Feature. Using `CountVectorizer` for text preprocessing, it achieves accuracy evaluation and predicts categories for new queries, automating customer issue classification.
# Support Ticket Classification System

## Project Overview
This project automatically classifies customer support tickets and assigns priority levels using Machine Learning and NLP.

## Features
- Text preprocessing
- Ticket classification
- Priority tagging
- Model evaluation

## Technologies Used
- Python
- NLTK / spaCy
- Scikit-learn
- Pandas
- Jupyter Notebook

## Workflow
1. Data Cleaning
2. Text Preprocessing
3. Feature Extraction (TF-IDF)
4. Model Training
5. Prediction & Evaluation

## Output
The model predicts ticket category and priority (High / Medium / Low).
